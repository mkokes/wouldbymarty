# WouldByMarty - E-Commerce Store

## Project Overview
- **Platform**: Medusa (open-source e-commerce)
- **Products**: Physical goods
- **Frontend**: Next.js Starter Storefront
- **Payments**: Stripe + Venmo
- **Hosting**: VPS (frontend) + Supabase (PostgreSQL)

## Tech Stack
- **Backend**: Medusa v2
- **Database**: Supabase (PostgreSQL)
- **Storefront**: Next.js
- **Payments**: Stripe, Venmo
- **Version Control**: GitHub

## Getting Started

### Prerequisites
- Node.js 18+
- Supabase account
- Stripe account (for payments)
- Venmo developer account

### Setup
1. Clone the repository
2. Set up Supabase database
3. Configure environment variables
4. Run development servers
